# G Borbon homepage

A responsive single-page website built with HTML, CSS, and vanilla JavaScript.

## Run it

Open `index.html` in a browser. No build step or dependency install is needed.

## Before publishing

1. Replace the temporary `G.` wordmark in `index.html` with the original G logo asset (the source attachment was not included in the copied conversation).
2. Replace the four overlaid brand names with the supplied transparent brand-logo files when they are available.
3. In `script.js`, set `endpoint` to the deployed Google Apps Script web-app URL. The form is deliberately not pointed at a guessed endpoint.
4. Update the email and Facebook link if different from the current placeholders.

## Images

`assets/network-scenes.png` is a four-frame image created for this project and used as the photographic backdrop for the network sections. Portfolio photos currently load from Unsplash, so replace them with approved project photography before launch.
